# Gaurav Sandilya — JavaScript Assignment 7

## DOM Manipulation and Events

This assignment implements the nine tasks from the supplied DOM assignment PDF using HTML, CSS, and core JavaScript (ES6+), without frameworks.

### Files
1. `Q1_Dynamic_Product_List_Manager.html` — Add/edit/delete products using event delegation; outside click saves edits.
2. `Q2_Live_Character_Counter.html` — 100-character counter, warning colors, `beforeinput`, `preventDefault()`, and Reset.
3. `Q3_Multi_Step_Form.html` — Three-step form with validation, Back/Next, and summary.
4. `Q4_Theme_Switcher.html` — Light, Dark, and Blue themes applied with `setAttribute()`.
5. `Q5_Image_Gallery_Modal.html` — Six-image gallery, modal preview, outside-click close, and `stopPropagation()`.
6. `Q6_Real_Time_Table_Filter.html` — Case-insensitive live filter and no-results message.
7. `Q7_Mouse_Path_Coordinates_Logger.html` — Mouse coordinates and red dots on double-click in a 400×400 box.
8. `Q8_Custom_Dropdown.html` — JavaScript dropdown with document click handling in the capturing phase.
9. `Q9_Form_Submit_Blocker_Live_Errors.html` — Form validation, `preventDefault()`, live error clearing, and success message.

## How to run
Open any `.html` file in a modern web browser. No frameworks or package installation are required.
