# Assignment 9 — jQuery

Ten exercises, each with its own `index.html` and `script.js`, plus shared `style.css`.

1. Welcome greeting: time-based greeting, quote change, visibility toggle, alert.
2. Product highlight: click highlight, hover details, favorite toggle, discount attribute selector, stock data attribute.
3. FAQ: click toggle, hover color, double-click collapse, input focus/blur styling.
4. Offers: hide/show, slide, fade and automatic five-second rotation.
5. Team directory: direct reports, `.next()`, `.children()`, siblings, `.parent()` and `.find()`.
6. Subscriptions: subscribe/unsubscribe, dynamically added topics, delegated `.on()`, `.off()`, status messages.
7. Course search: `.keyup()` filtering, `.css()`-style matched highlighting, count and clear.
8. Blog posts: append, prepend, remove, `.before()`, `.after()`, keyword highlighting.
9. Multiple jQuery versions: jQuery 3.7.1 and 2.2.4 with `noConflict(true)` aliases.
10. Registration validation: required name, email format and sample uniqueness, password length, invalid-field styling.

Open each `index.html` in a browser with internet access. The email uniqueness check in Q10 uses sample client-side data; real uniqueness needs a backend/database. This is a front-end assignment demo.
