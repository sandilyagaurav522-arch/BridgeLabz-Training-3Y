# Gaurav Sandilya — JavaScript Assignment 6

## Lec 17–20: Async Programming with JavaScript

This assignment contains separate JavaScript solutions for all 10 questions in the supplied assignment PDF.

### Files
1. `Q1_Async_Coffee_Maker.js` — Promise chaining and error handling
2. `Q2_Microtasks_vs_Macrotasks.js` — Event loop task order
3. `Q3_Bug_Tracker_Promise_Migration.js` — Callback-to-Promise migration
4. `Q4_Async_Timeout_Race.js` — `Promise.all()` and `Promise.race()`
5. `Q5_Callback_Hell_vs_Async_Await.js` — Nested callbacks and async/await
6. `Q6_Fake_Store_Product_Fetcher.js` — Fetch API and optional product cards
7. `Q7_Promise_AllSettled_Lazy_Loader.js` — `Promise.allSettled()` and timing
8. `Q8_Order_Processing_Retry.js` — Retry logic
9. `Q9_Debugging_Event_Loop.js` — Predicted event-loop output
10. `Q10_Async_Delivery_Pipeline.js` — Sequential asynchronous pipeline

## How to run
- Install Node.js if it is not already installed.
- Open a terminal in this folder.
- Run one file at a time, for example: `node Q1_Async_Coffee_Maker.js`
- Q6 uses the Fetch API. Use a recent Node.js version (Node 18+) or run it in a browser console.
- Q6's optional product cards render only when the script is used on an HTML page containing an element with `id="product-container"`.

Some questions deliberately use random failures, so output can differ between runs.
