# Assignment 10 — Bootstrap 5

This folder contains ten responsive Bootstrap 5 exercises based on the supplied assignment PDF.

## Structure
Each `assignment-N-*` folder contains a separate `index.html` and `style.css` file.

1. Company landing page — Bootstrap navbar, container, row, columns, hero.
2. Personal portfolio — spacing, typography, image, buttons, and form utilities.
3. Product catalog — responsive grid with four product cards and hover effects.
4. Restaurant menu — responsive Bootstrap table, list group, food image and caption.
5. Themed blog — custom Bootstrap CSS variables, Google Fonts, cards and footer.
6. Notifications dashboard — success/info/danger alerts, dismissible alert, summary panel.
7. Task tracker — list group, priority badges, pending counter and completed buttons.
8. Pricing plans — three responsive cards with highlighted Pro plan and hover effects.
9. Blog pagination — centered pagination and older/newer pager buttons.
10. Travel showcase — three-slide Bootstrap carousel, custom slide intervals, animated 70% progress bar and contact footer.

## Run
Open any `index.html` file in a modern browser. Bootstrap 5.3.3 is loaded via CDN, so an internet connection is needed for Bootstrap styling and remote images. Bootstrap JavaScript is included only on pages requiring interactive components (navbar collapse, dismissible alert, and carousel).

## Notes
- Each assignment has its own CSS file.
- Semantic HTML5 elements are used throughout.
- Grid and Flex utilities keep layouts responsive.
- Buttons/forms are demonstration UI unless a real backend is connected.
