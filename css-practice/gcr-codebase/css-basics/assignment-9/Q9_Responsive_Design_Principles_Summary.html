Responsive Design Principles

Fluid Layouts

Use flexible units so layout width adapts to the viewport.

.container { width: min(90%, 1100px); margin: auto; }

Flexible Media

Prevent images from overflowing their containers.

img { max-width: 100%; height: auto; }

Breakpoints

Adjust the layout when content needs more room.

@media (max-width: 600px) { .grid { grid-template-columns: 1fr; } }
