Responsive CSS Cheat Sheet

Filters

Apply visual effects to images.

filter: grayscale(1);

Media Queries

Apply styles at chosen screen widths.

@media (max-width: 700px) { ... }

Responsive Design

Build layouts that adapt to different devices.

width: 100%; max-width: 1100px;

Typography

Scale text smoothly between sizes.

font-size: clamp(1rem, 2vw, 1.5rem);

CSS Grid

Create two-dimensional layouts.

grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));

Flexbox

Align items along a row or column.

display: flex; gap: 1rem;
