Default: content-box

Width = 300px
Padding = 30px
Border = 5px

Total rendered width becomes larger than 300px because padding and border are added.

border-box

Width = 300px
Padding = 30px
Border = 5px

Total rendered width remains 300px because padding and border are included inside the declared width.
